# خيارات قوائم الأصناف والحسابات — 2026-10-12

تفعّل هذه الدفعة علمي «في القائمة» و«في البحث» في قوائم الأعمال الرئيسية للأصناف والحسابات، بعد إدارة التعريفات والقيم الموثقة في CONFIGURATION_MANAGEMENT.md. لا توسّع أنواع السجلات أو تغيّر حقول الفواتير أو قوائم الاختيار التشغيلية.

## السلوك

تظهر الخيارات الفعالة ذات showInList كأعمدة إضافية قبل عمود الإجراءات، مرتبة حسب sortOrder ثم المعرف. يعرض نعم/لا للقيم المنطقية، وعنوان الاختيار للقوائم، والأعداد والتواريخ كما حُفظت بدقتها، وغير محدد للقيمة الغائبة أو null. الحقول النظامية تستمد قيمتها من active وhas_expiry؛ لا تنشأ نسخة ثانية من القيمة، ولا يستبدل افتراضي التعريف قيم السجلات القديمة.

يشمل البحث العام q قيم الخيارات الفعالة ذات searchable؛ تستخدم القوائم العنوان الظاهر، والقيم المنطقية نعم/لا. تتحد هذه النتائج مع البحث الأساسي وتخضع كلها لتصفية الشركة والحقول الأساسية. خيار قابل للبحث وغير ظاهر في القائمة يمكن البحث فيه، دون إضافة قيمه إلى optionValues التي تعيدها صفوف القائمة.

يمكن اختيار تصفية إضافية واحدة، مع إبقاء البحث والتصفية الأساسية والترتيب المتعدد. النص يقبل يساوي/يحتوي؛ الأعداد والتواريخ تقبل يساوي وأكبر/أصغر أو يساوي؛ القيم المنطقية والقوائم تقبل اختيارًا مطابقًا. جميع الأنواع تقبل محدد/غير محدد. false و0 قيم محددة. إدخال التصفية مرحلي، ولا يرسل إلى الخادم إلا بزر تطبيق حتى لا يرسل تاريخًا أو عددًا ناقصًا أثناء الكتابة.

أرشفة التعريف تزيل عموده ومشاركته في البحث والتصفية، وتحتفظ بالقيمة في كرت السجل للعرض. الرابط المحفوظ بفلتر أو ترتيب خيار غير متاح يعيد خطأ واضحًا؛ توفر الواجهة إزالة التصفية أو ترتيب الخيارات دون إزالة بقية فلاتر المستخدم. الحفظ من الدليل أو الكرت يبطل ذاكرة قوائم الشركة والمستخدم المعنيين، فتنعكس التغييرات عند القراءة التالية.

## الخادم

GET /api/companies/:companyId/items و/accounts يعيدان الصفحة الحالية مع optionDefinitions للخيارات الفعالة الظاهرة أو القابلة للبحث. كل سجل يضيف optionValues بمفاتيح معرفات الخيارات الظاهرة فقط. يستخدم الترتيب option.ID:asc أو desc؛ تقارن الأعداد كـ NUMERIC والتواريخ كـ DATE، مع معرف السجل لكسر التعادل. لا تحويل إلى Number للأعداد المالية أو الكبيرة.

تصفية الخيار تستعمل optionId وoptionOperator وoptionValue. العمليات المسموحة eq/contains/gte/lte/empty/filled حسب النوع. يتحقق الخادم من نوع القيمة وصحة التاريخ وإتاحة التعريف والشركة؛ لا يقبل اسم عمود أو مقطع SQL من المستخدم. تُمرّر قيم البحث والتصفية كمعاملات SQL. تحافظ القوائم على صلاحيات الوحدة والمنع الصريح؛ إدارة دليل الخيارات وحدها لا تمنح بيانات الأصناف أو الحسابات.

تُقرأ التعريفات والعدد والصفوف والقيم في snapshot متسق لكل طلب. تُجلب قيم الصفحة دفعة واحدة، وتضاف في الترحيل 015 فهارس مخصصة لتعريفات القوائم وقيم كل كرت. لا يغير الترحيل أي قيمة أو صلاحية أو حالة سجل.

## التحقق

فحص TypeScript وبناء الواجهة، واختبارا API فقط ببادئة option lists يغطيان الأعداد الكبيرة والتواريخ والاختيارات والقيم الناقصة وعزل الشركات والأرشفة والحقول النظامية. browser-option-lists.ts يراجع الأعمدة والترتيب والبحث والتصفية والهاتف والأرشفة وإزالة الفلتر القديم. نجحت هذه الفحوص المحددة؛ لم تُشغّل مجموعات النظام أو المتصفح العامة. يتطلب إعلان النشر تأكيد Railway SUCCESS وتشغيل الخدمة للإصدار نفسه.
