## إرشادات المطور الحية (الموقع)

- الاسم: «دليل استخدام الموقع للمطور»؛ `groupId=3`؛ `slug=site-developer-guide`.
- المسارات نسبية إلى `/api`:
  - `GET /api/explanations/groups/3/tree`: فهرس/عُقد الدليل (معرفات وعناوين، لا النص الكامل).
  - `GET /api/explanations/groups/3/document?offset=0`: قراءة متصلة **مجزأة**؛ كرر الطلب بزيادة `offset` بعدد عناصر `nodes` الفعلية حتى `hasMore=false`.
  - `GET /api/explanations/groups/3/topics`: رؤوس الفصول.
  - `GET /api/explanations/topics/:topicId`: فصل كامل بأبنائه.
  - `GET /api/explanations/nodes/:nodeId`: تفاصيل عقدة واحدة.
- دليل المطور يسمح بالقراءة للحساب النشط المسجل دخولًا. **لا تخلط بين امتلاك URL وامتلاك تفويض**. اتصالات أدوات ChatGPT تعمل عبر OAuth مخصص؛ الأداة الأخرى قد تحتاج ربطًا مستقلاً.
- إن كان مكوّن «الرئيسي» متاحًا ومفوضًا في بيئة الأداة، ابدأ بـ `tijara_api_catalog` ثم `tijara_api_read` بالعملية المعلنة. لا تخمّن شكل الطلب أو خادم MCP.
- إن ظهرت `403`، ميّز هل الرفض صادر من سياسة خروج الإنترنت لبيئة المساعد، أم من الموقع (جلسة/صلاحيات)، أم من رمز OAuth. السماح بالنطاق لا ينشئ جلسة ولا يمنح صلاحية. لا تتجاوز قيود الجلسات أو CSRF.
- لا تستخدم `document?all=true` للقراءة المعتادة؛ مخصص للطباعة.
- بعد العمل، حدّث الدليل عبر العمليات المعتمدة (إن كان التفويض كافيًا)، وأعد القراءة للتحقق. إن تعذر الاتصال لا تدّع نجاح القراءة أو الحفظ.

## GitHub وRender وأداة التطوير

1. اربط الأداة الحالية بالمستودع عبر التكامل الرسمي المتاح **لها**، وتحقق من فرعها قبل التعديل.
2. اربط Render عبر التكامل/المكوّن المصرح المتاح **داخل الأداة نفسها**، أو عبر Render API/CLI بعد ضبط سرّ خاص بها. خادم Render MCP الرسمي موثّق أعلاه، لكنه قد لا يكون متاحًا لكل عميل أو وضع تشغيل.
3. تحقق قراءةً من مساحة العمل والخدمات دون تغييرها.
4. النشر التلقائي لخدمة الويب **متوقف** وفق إعداد Render الذي فُحص في 2026-11-04: رفع commit لا يعني أن التعديل نُشر. عند تفويض نشر محدد، شغّل النشر يدويًا وتابع الحالة `live` ثم `/api/health`.
5. استخدم `npm ci` وفق بيئة المشروع وشغّل `npm run check` واختبارات التغيير قبل أي نشر. لا تشغّل اختبارات مدمرة على قواعد الإنتاج.
6. لا تعد إلى Railway؛ هو مزود قديم. لا تغيّر الخطط المدفوعة أو إعدادات الإنتاج بسبب مهمة توثيق/اتصال.
