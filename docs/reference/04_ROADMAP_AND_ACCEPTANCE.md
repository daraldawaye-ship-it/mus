# مراحل التنفيذ ومعايير القبول

## المرحلة 1: الأساس والهوية

**النطاق:** إعداد المشروع، العربية RTL، تسجيل الدخول، ملف المستخدم، إنشاء الشركات من المالك، العضويات والأدوار والصلاحيات، الشركة النشطة وآخر شركة، سجل الأحداث الأساسي، تخطيط متجاوب.

**القبول:**
- لا يستطيع غير المالك إنشاء شركة.
- لا يرى عضو شركة بيانات شركة أخرى بتغيير الرابط أو الطلب.
- المستخدم يستعيد آخر شركة مسموح بها؛ إذا سحبت العضوية يذهب إلى شركة أخرى متاحة.
- المظهر واللون يحفظان منفصلين لكل مستخدم ولكل شركة.
- أحداث الدخول وإنشاء الشركة وتغيير بيانات أساسية تسجل بفاعل ووقت وهدف.
- تشغيل المشروع واختباراته موثقان.

## المرحلة 2: دليل الصفحات والصلاحيات والخصائص

**النطاق:** كرت الصفحات، سجل الوظائف، البحث، الظهور، أدوار قابلة للتخصيص، خصائص السجلات، إعدادات الشركة والترويسة.

**القبول:** صفحة لا تظهر للمستخدم دون إذن، ويُرفض الوصول إليها من الخادم أيضًا. الخصائص معرفة ومقيدة بنوع الصفحة، ويظهر سجل تغييراتها.

## المرحلة 3: دليل الحسابات والعملات

**النطاق:** شجرة الحسابات، ترقيم 10 أرقام، حسابات حركة/مجموعة، توليد حسابات العملاء والموردين والصناديق، العملات وأسعار الصرف، الحسابات النظامية.

**القبول:** لا ترحيل إلى حساب مجموعة، لا تكرار للكود داخل الشركة، وترقيم الحسابات الجديدة ثابت الطول، والأرصدة تستخدم دقة مالية صحيحة.

## المرحلة 4: الأصناف والمواقع والمخزون

**النطاق:** كرت الصنف والوحدات، الوكلاء، الرفوف، التركيب، الفروع والمعارض والمخازن، حركة الأصناف والمناقلات والتسوية.

**القبول:** تحويلات الوحدات صحيحة، المخزون معزول حسب الفرع/الموقع، التسوية تحفظ الفرق، وسياسة المخزون السالب مطبقة في الخادم.

## المرحلة 5: فواتير المبيعات والمشتريات

**النطاق:** إدخال سريع، بحث أصناف، وحدات وأسعار، بيع وشراء ومردودات، طباعة، خصم، حساب مقابل، استلام حسب الموقع.

**القبول:** تخطيط عملي للشاشة والهاتف، إجمالي السطر والإجمالي العام يتحدثان فورًا، وتُحفظ الفاتورة وحركات المخزون والقيد في عملية آمنة واحدة.

## المرحلة 6: السندات والقيود والحركات الموحدة

**النطاق:** قبض وصرف وقيود يدوية وكشف حساب، ترحيل مجمع، عكس وإلغاء، صفحات حركة قيود وحركة أصناف وتقارير.

**القبول:** القيد متوازن، الحسابات المتكررة مجمعة بحسب الحساب والأبعاد، تفاصيل الأصناف محفوظة، وكل مبلغ مجمع قابل للتتبع للمصدر، ولا تتكرر القيود عند إعادة المحاولة.

## المرحلة 7: الموظفون والمذكرات والنقاط

**النطاق:** كرت الموظف، سير المذكرة والإحالة والمصادقة، إشعارات، كرت النقاط، سجل المحفظة وترحيل النقاط.

**القبول:** الربط بالمستخدم إلزامي للموظف، المذكرة لا تغلق قبل مصادقة المرسل، صلاحيات المتابعة محترمة، وقواعد عدم التكرار للنقاط صحيحة.

## المرحلة 8: الدليل العام ومراجعة الجمهور

**النطاق:** صفحات المتاجر والخدمات والمنتجات العامة، اقتراحات الجمهور، المراجعة والاعتماد، توثيق الملكية، التعليقات والإعجابات والبحث.

**القبول:** مساهمات الجمهور لا تصبح عامة قبل الاعتماد؛ يظهر من أنشأ وعدل واعتمد؛ يمكن ضبط من يرى ويحرر كل سجل؛ صفحات العرض العامة قابلة للفهرسة.

## المرحلة 9: التهيئة للهاتف والميزات المستقبلية

**النطاق:** API مستقلة، تجربة تطبيق ويب قابلة للتثبيت، الإشعارات، اختبار الهاتف، عقود تكامل مستقبلية للدردشة والبريد والأرشيف والتقويم ومساعد الذكاء الاصطناعي.

**القبول:** الوظائف الأساسية لا تعتمد على مكونات متصفح خاصة بالكمبيوتر، وواجهات API تفرض المصادقة والصلاحيات وعزل الشركات.

## معايير مشتركة لكل مرحلة

- اختبار نجاح وفشل، واختبار صلاحيات وعزل شركات.
- مراجعة أخطاء الهاتف والكمبيوتر، ودعم RTL ولوحة المفاتيح.
- migrations قابلة للتطبيق دون إسقاط بيانات غير مقصود.
- سجل تدقيق للعمليات الحساسة، ورسائل خطأ عربية مفهومة.
- ملخص يذكر الملفات/الصفحات المتأثرة، ما تم اختباره، وما بقي للمرحلة التالية.
