# حذف الحركة التجريبية — 2026-10-15

طلب المستخدم صراحة حذف جميع فواتير وسندات دار الدواء وحركتها السابقة دون نسخة احتياطية، مع إبقاء الدليل والأصناف والمستخدمين. هذه عملية صيانة منفصلة عن الترحيل والعكس المعتادين؛ لا تسمح بتعديل مستند مرحل في العمليات اليومية.

وسّع المستخدم الطلب في الجلسة نفسها إلى جميع الشركات لأن الحركة كلها تجريبية. يُنفّذ الحذف لكل شركة مؤكدة من قائمة الشركات، بمعاينة وبصمة وطلب مستقلين، ويُراجع خلو الحركة في كل شركة بعد التنفيذ. لا تُحذف الشركات أو بياناتها الأساسية.

`GET /companies/:companyId/transaction-reset` يعرض الأعداد والبصمة وأسباب المنع لمالك المنصة فقط. `POST` يتطلب اسم الشركة مطابقًا، والبصمة نفسها، و`deleteAllTransactions:true` وUUID ثابتًا. يُعاد فحص المالك والشركة والصفحات وإغلاق الشركة قبل التعديل. إذا تغير أي سجل مشمول منذ المعاينة، يُرفض الطلب دون حذف.

تُحذف الفواتير وأسطرها، المستندات المالية وأسطرها، العمليات والحركات والأرصدة المخزنية وخيارات المستندات المرتبطة داخل معاملة واحدة. تُصفّر صفوف تقييم المخزون ويُعاد بناء إحصاءات الأصناف. تُفحص القيود المؤجلة قبل إغلاق صلاحية الحذف المحددة بالشركة والمعاملة؛ لا يُعطّل أي مشغّل أو مفتاح أجنبي.

تبقى الحسابات والأصناف والعملات والفروع والمواقع والموظفون والمستخدمون والإعدادات وسجل التدقيق والعدادات. تبقى المذكرات وروابطها كسجل تاريخي؛ الرابط إلى مستند محذوف لا يفتح سجلًا آخر. تُحذف مكافآت الفواتير وطلبات طباعة السندات المحذوفة وعكوسها فقط، ويُطرح صافي نقاطها بدقة من المحافظ داخل المعاملة نفسها، مع إبقاء الدوام والدخول وزيارات الصفحات والمكافآت المستقلة. التحويل المالي المرتبط بالقيود، أو نقص النقاط المتاحة بعد مراعاة الحجوزات، يمنع العملية كلها دون تعديل جزئي.

المحفوظ عن التنفيذ هو الأعداد والفاعل والوقت وطلب التأكيد ونتيجته، دون نسخ بيانات المستندات المحذوفة. إيصال UUID ثابت يحمي إعادة المحاولة بعد إنشاء حركة جديدة؛ إعادة الطلب المقبول تعيد النتيجة السابقة دون حذف جديد، والطلب المختلف بالمفتاح نفسه يُرفض.
