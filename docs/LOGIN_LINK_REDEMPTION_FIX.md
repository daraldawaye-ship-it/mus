# منع انتهاء روابط الدخول عند المعاينة ومعالجة رفض التخزين المحلي — 3 نوفمبر 2026

## السبب في الكود السابق
كان `apps/web/src/QuickLoginPage.tsx` ينفذ `POST /auth/login-link/redeem` داخل `useEffect` فور تحميل الصفحة. الخادم في `routes-auth.ts` يستهلك رابط الدخول استخدامًا واحدًا ذريًا عبر `DELETE ... RETURNING` في PostgreSQL. لذلك قد يتوقف الرابط حتى خلال دقائق إذا فتحت معاينة أو عارض متصفح الرابط فعليًا، أو إذا فُتح ثم نُسخ إلى متصفح/تطبيق آخر. الرابط مدته الرسمية **ساعة** من إنشاء الرمز، ويُلغى الرابط السابق عند إصدار رمز جديد للحساب نفسه.

في `apps/web/src/api.tsx` كان `adoptLiveAuthentication` ينتظر `setOfflineLoginRequired(false)` على IndexedDB المحلي قبل قبول جلسة تم إنشاؤها فعليًا في الخادم. إذا رفض متصفح الهاتف التخزين المحلي (`The user denied permission to access the database`)، تخرج الواجهة بخطأ تسجيل دخول رغم نجاح API، بعد استهلاك الرابط أحادي الاستخدام.

## الإصلاح
- صفحة `/quick-login#TOKEN` تقرأ الرمز إلى `ref` في الذاكرة ثم تزيل `#TOKEN` من عنوان المتصفح فورًا؛ لا تضع الرمز في localStorage أو query أو HTTP logs. لا ترسل الطلب حتى يضغط المستخدم زر **«دخول إلى الحساب»** صراحة. بذلك لا يُستهلك الرابط عند فتح الصفحة أو معاينة الرابط.
- احتفظ بمدة **ساعة** وحد الاستخدام الواحد، وباشتراط المالك لإصدار الرابط، وبصمة SHA256 على الخادم، وقيد المحاولات، والفحص المأمون لـ Origin وCSRF، وإلغاء الرابط السابق عند توليد رابط جديد. عدم السماح بإعادة استخدام رمز مستخدم أو مسروق مقصود.
- قبول الجلسة الصحيحة عبر الإنترنت مستقل عن نجاح حفظ علامة التخزين الاختيارية في IndexedDB؛ فشل `setOfflineLoginRequired(false)` لا يرفض جلسة المصادقة. تستمر قواعد الأوفلاين وفحص الصلاحيات بالخادم دون توسيع.
- في نافذة إنشاء الرابط يُعرض توضيح أن الاستخدام يكون عند تأكيد المستخدم، وأن الإصدار الجديد يلغي السابق.
- اختبار `tests/user-magic-link-login.test.ts` يثبت أن POST redemption موجود فقط في معالج الزر وأن قبول الجلسة لا يتوقف على IndexedDB، إلى جانب الاختبارات السابقة. .github/workflows/user-magic-link-ci.yml يشغّل `npm run check` و`npm run build` والاختبار المذكور.

## للمستخدم
الطريقة الموثوقة: **المستخدم يفتح الرابط الأخير كاملًا في المتصفح ثم يضغط «دخول إلى الحساب»**. إذا ظهر «الرابط مستخدم أو منتهي» بعد هذا التحديث، ربما استُعمل فعلًا أو أُلغي بسبب إصدار رابط أحدث؛ أنشئ رابطًا جديدًا مرة واحدة وأرسله مباشرة. إذا كان المتصفح يمنع التخزين المحلي، يستمر الدخول عبر الإنترنت؛ لكن العمل دون اتصال قد يحتاج إعدادات تخزين الجهاز المناسبة ولا ينبغي حذف بيانات التطبيق المخزنة بلا مراجعة إذا توجد مسودات لم تُزامن.
