# أساس الخيارات والصلاحيات — الدفعة الأولى، 2026-10-12

هذه الدفعة تنفذ قاعدة البيانات والعقود وقراءة ملخص الأساس فقط، وفق طلب المستخدم تقسيم العمل والنشر دون تشغيل اختبارات. شاشات إدارة الدليل، حفظ الخيارات من الكروت، وتفعيل قرارات الأدوار الجديدة مراحل تالية؛ واجهة الموقع الحالية لم تتغير في هذه الدفعة.

## الخيارات

الترحيل 012 ينشئ قائمة موحدة option_definitions، ويربط التعريف بصفحة مسجلة وبنوع سجل معروف. يدعم نعم/لا، نصًا، عددًا صحيحًا أو عشريًا دقيقًا ممثلًا بسلسلة، تاريخًا صحيحًا، وقائمة ذات مفاتيح ثابتة وعناوين. يحمل الافتراضي والإلزام والبحث والظهور والترتيب والحالة والإصدار والمنشئ والمحدّث. القيم الاختيارية منفصلة في option_values؛ مراجع الأصناف والحسابات والموظفين والفواتير والمستندات المالية حقيقية ومقيدة بالشركة عبر مفاتيح مركبة. الفواتير والمستندات المالية النهائية محمية من تغيير القيم.

تُعرّف تلقائيًا للشركات الموجودة والجديدة ثلاثة خيارات نظامية: أرشفة الصنف، له تاريخ انتهاء، وأرشفة الحساب. التعريفات تشير إلى الأعمدة الأصلية: الأرشفة معكوس active، والانتهاء has_expiry. تمنع قاعدة البيانات تخزين قيمة إضافية لهذه الخصائص منعًا لتعارض مصدرين. القيم الحالية للسجلات لا تُعدّل. الافتراضي في الدليل لا يغيّر حاليًا افتراضي نموذج الكرت؛ ربط النماذج يأتي لاحقًا. الكمية والسعر والعملة تبقى أعمدة أعمال مستقلة، ولا تُضاف «محاسب» أو «صنف خدمي» كخيار شكلي.

تمنع القيود تغيير هوية التعريف أو تفسير قيم محفوظة بنوع جديد، وتلزم زيادة الإصدار عند تعديل التعريف والقيمة. تعريفات الخيارات تؤرشف بدل الحذف. قيم الدليل لا تكتب من API في هذه الدفعة؛ التدقيق ومعالجة التعارض لكل كتابة مستقبلية يجب أن يكونا في المعاملة نفسها.

## الصلاحيات والأدوار

الترحيل 013 يسجل الإجراءات الثمانين الفعلية لصفحات الشركة مع شروطها الحالية. ينشئ أدوارًا خاصة بكل شركة، وروابط تسمح بأكثر من دور للموظف، وقواعد سماح/منع للأدوار واستثناءات الموظفين. المفاتيح المركبة تمنع ربط دور أو موظف من شركة أخرى. الأدوار الخمسة النظامية تضاف للشركات الحالية والمستقبلية، ولا تُمنح صلاحيات أو تُربط بالموظفين تلقائيًا.

تبقى employees.permissions وقواعد الخادم الحالية مصدر قرار الوصول في هذه الدفعة. الجداول الجديدة لا تمنح وصولًا بمجرد إضافة صف؛ تفعيلها سيأتي مع مرحلة الخادم والإدارة، مع اعتبار المنع الصريح أقوى من السماح، والحفاظ على العضوية الفعالة وحماية المالك والمدير العام وحالة المستند. صلاحية إظهار الصفحة أو إدارة دليلها لا تمنح بيانات الوحدة.

## القراءة والنشر

GET /api/companies/:companyId/configuration-foundation يعيد عدد التعريفات والقيم والأدوار والروابط والقواعد، ومعاينة محدودة من الخيارات والأدوار. يتحقق من المستخدم الحالي والعضوية وصلاحية pages.manage قبل القراءة، ويعلن صراحة أن الحالة foundation وأن صلاحيات الموظف القائمة لا تزال نافذة. لا يعيد قيم السجلات أو هويات الموظفين.

ترحيلات PostgreSQL تطبق آليًا في معاملة عند بدء الخدمة، مع قفل يمنع الترحيل المتزامن. تتطلب الخدمة نجاحها قبل الاستماع. في هذه الدفعة يُجرى بناء النسخة وتجميع TypeScript فقط؛ لا تُشغّل اختبارات نظام أو متصفح. يُعلن النشر بعد نجاح إصدار Railway وتشغيل الخدمة.
