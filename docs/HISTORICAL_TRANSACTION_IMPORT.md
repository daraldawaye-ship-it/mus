مسار المالك `GET/POST /companies/:companyId/transaction-import/source-dates` يعاين ثم يصحح الفواتير والسندات المستوردة وقيود الفاتورة الرئيسية والتكلفة والفروق وحركات مخزونها. المعاينة ببصمة جميع السجلات المحمية للشركة؛ طلب التنفيذ UUID ثابت ونظام مصدر وبصمة المعاينة. الصلاحيات والصفحات وعزل الشركة والتدقيق داخل المعاملة. لا يرسل المستدعي معرفات سجلات أو تواريخ بديلة حرة؛ يستخرج الخادم كل هدف وتاريخه من ربط المصدر الموثق. حراسة قاعدة البيانات تسمح بتغيير عمود التاريخ فقط لهدف مربوط بتاريخ قبل/بعد محدد ومعرّف المعاملة الحالية. السجلات التجريبية وغيرها تبقى خارج التصحيح.

يعاد بناء أيام إحصاءات الأصناف المتأثرة وحقائق أسعار المشتريات وتجميعاتها، بما فيها الفواتير العادية التي تشترك في اليوم والصنف؛ وتعمل محركات إحصاءات التركيب المعتادة. تبطل ذاكرة إحصاءات الحسابات المؤرخة. تحفظ بصمة كل الأعمدة الأخرى والسطور والأرصدة والتقييمات قبل/بعد ويُسجل فرق التواريخ الفعلي بالتدقيق. فشل التدقيق يرجع العملية كاملة. إيصال UUID غير قابل للتعديل، والطلب المقبول المعاد لا يغير حركة لاحقة. تبقى بصمات طلبات الاستيراد وإيصالاتها الأصلية كما كانت؛ لا تتكرر المستندات عند إعادة طلب قديم.

مسار المالك `POST /companies/:companyId/transaction-import/batch` يرحل إلى جداول الفواتير والمخزون والدفتر الموجودة وخدماتها نفسها. جدول المصدر فهرس للربط والتدقيق وعدم التكرار، وليس دفتر حركة مستقلًا. الهوية الفريدة شركة+نظام مصدر+نوع+معرف مصدر؛ السند يستخدم معرف الحركة لأن أرقام السندات تتكرر. UUID ثابت للدفعة ومفتاح المستند والبصمة الكاملة تمنع تكرار الطلب أو تغيير المصدر المقبول صامتًا.

في السندات المصدرية `معرف_الحساب` هو الصندوق و`معرف_الصندوق` هو الحساب المقابل؛ إشارة المبلغ تحدد القبض أو الصرف الفعلي مع حفظ النوع القديم. تبقى السندات المرتبطة والتحويلات عبر الحساب الوسيط كحركات منفصلة؛ لا تتحول كل حركة منها إلى تحويل نقدي مباشر مكرر. تعرّف الحسابات المستوردة المصنفة أصلًا `cashbox` صراحةً كصناديق عبر API الحسابات، دون تغيير هويتها أو فئتها. تحفظ أرقام الوصول المصدرية في البيانات الأصلية دون تسميتها أرقام وصول مورد حين تكون معرفات ربط.
