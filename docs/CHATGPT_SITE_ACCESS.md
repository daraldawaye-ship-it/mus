# ChatGPT site access

The existing `/mcp` connection retains its four general-table tools. Three new tools expose the current JSON domain API: `tijara_api_catalog`, `tijara_api_read`, and `tijara_api_write`. Browser and MCP requests use the same business router, page gates, permission request context, validators, transactions, optimistic revisions, exact numeric handling and audit records. Password/session/setup/media endpoints are excluded. No arbitrary URL, SQL or cookies are accepted.

OAuth consent remains limited to active platform owners/public administrators; company access still follows the account's actual membership and permissions. Existing grants do not gain privileges. New read scope is `general_table.read tijara.read`; full read/write is `general_table.read general_table.write tijara.read tijara.write`. Migration 061 permits these grants without changing any existing authorization. Revocation and expiry apply on every tool call.

The catalog is built from the registered domain routes. Request contracts are generated from the same Zod schemas, with source expressions for inline validators. Regenerate after route/contract changes with `npx tsx scripts/generate-mcp-contracts.ts`. Catalog schemas describe structure; validation of relationships and cross-field refinements remains authoritative in the API. Use an exact operation from the catalog, substitute its named `pathParams`, and provide `query` and `body` separately. Responses preserve the API HTTP status in `structuredContent.status`, the original payload in `data`, and mark errors with `isError`.

Employee setup: resolve company and public user IDs; inspect an existing employee's permissions, attendance settings, record options and role assignments. Create using the existing userId and explicit createSalesCashbox when requested. The domain service creates separate advance/pouch/cash accounts and wallet records transactionally. Save attendance settings and options separately using their current revisions. Never reuse another employee's private account binding or infer hourly points/normal hours.

After deployment, refresh the existing App's MCP tools in its developer configuration, then reconnect and approve the new OAuth scope. This repository cannot refresh ChatGPT's cached App tool catalog. Publication of server code alone does not activate tools in an existing conversation or expand its authorization.

Validation: focused ChatGPT OAuth/API tests include old grant rejection, consent, read-only write rejection, employee/account creation, duplicate protection, attendance revisions, company isolation, disabled pages, path rejection, public-admin company denial and immediate revocation. Existing focused manager/configuration tests also pass. An older public-administration search test fails at its email-search assertion on the baseline as well; this change does not alter that lookup.
