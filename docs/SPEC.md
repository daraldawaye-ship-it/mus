# الرئيسي | Alraesy — مواصفات البداية الجديدة

## النطاق الحالي

اكتمل أساس الحساب العام والشركات والموظفين والتنسيق، وإدارة دليل الحسابات والعملات وأسعار الصرف والفروع والمعارض والمخازن. قواعد المرحلة الثانية ومعايير قبولها في PHASE_2.md، ونتائج التحقق في README.md. المرحلة الثالثة تضيف القيود اليدوية وسندات القبض والصرف والأرصدة وكشف الحساب وفق PHASE_3_ACCOUNTING.md. المرحلة الرابعة أ تضيف كروت الأصناف والوكلاء والوحدات الثلاث وأسعارها ومعاينة التحويل الدقيق وفق PHASE_4_ITEMS.md. التوجيه الحالي يضيف فواتير المبيعات والمشتريات والمردودات والمخزون والمناقلات والجرد وفق PHASE_5_COMMERCE.md. يبقى الدليل العام التشغيلي والمذكرات والمكافآت لمراحلها. محفوظات التنفيذ القديم خارج المشروع، والمواصفات الأصلية في reference للمتطلبات المستقبلية.

## الهوية والنطاق

المستخدم يسجل ويدخل الموقع العام دون أي شركة تلقائية. هويته عامة: الاسم، اسم الظهور، البريد، الهاتف، الصورة، كلمة المرور. الأنواع: إدارة، مشرف، عضو؛ حالات مؤرشف، موقوف عن المشاركة؛ صلاحيات محرر، مراقب. ملكية المنصة مستقلة ومحمية. الدخول الأول للعام.
الدليل العام لاحقًا قابل للبحث للمتاجر والمحلات والمنتجات والأطباء والعيادات، ومساهمات الجمهور تحتاج مراجعة واعتمادًا وتوثيق ملكية وتعليقات وإعجابات. الدردشة عامة. API مستقلة لتطبيقات Android/iPhone وإشعارات مستقبلية.

## الشركات

المالك وحده ينشئ الشركات. المالك يدخل كل الشركات دون موظف. غير المالك يدخل فقط من موظف فعال مرتبط بمستخدم موجود بمعرف ثابت. هاتف الموظف مستقل ويساعد البحث ولا ينشئ عضوية. أكثر من شركة لنفس المستخدم مسموح.
المالك يعين عدة مديرين عامين من الموظفين؛ جميعهم لهم صلاحيات الشركة كاملة. المدير يدير الموظفين العاديين والأدوار والصلاحيات؛ لا يمنح/يسحب صفة مدير عام أو يعطل مديرًا آخر. الإدارة العامة لا تمنح صلاحيات داخل شركة. في الأساس الجديد أرشفة حساب مدير عام فعال للمالك فقط، مع تسجيل أثرها.
أدوار قابلة للتوسعة: موظف، إداري، محاسب، مبيعات، مشتريات. إلى صلاحيات بيانات الشركة والموظفين والسجل تضاف صلاحيات القراءة والإدارة للحسابات والعملات والمواقع. الإدارة تشمل القراءة، ولا تضاف صلاحيات جديدة تلقائيًا إلى موظف موجود. وظائف الوحدات المستقبلية تؤجل إلى مراحلها.
المبيعات والمشتريات والسندات والحسابات والمخزون والتركيب والمذكرات تتبع الشركات. النقاط والمحفظة مرتبطة بالموظفين داخل شركتهم. وصول غير الموظفين لاحقًا بمنح محددة أو روابط قابلة للإلغاء دون تحويلهم لموظفين.
آخر شركة تُحفظ مع إعادة تحقق العضوية والسقوط إلى شركة أخرى متاحة. الموقع العام يظل نقطة الدخول الافتراضية، وروابط الشركات مباشرة وقابلة للتحديث.

## التدقيق

سجل أحداث عام وسجل لكل شركة بصلاحيات منفصلة. سجل كل تغيير مع الفاعل والوقت ومعرف السجل والقيم الفعلية قبل/بعد بعد التطبيع. المعاملة تشمل التغيير والسجل. لا قيم سرية. كل عملية تعديل حساسة ومدخل صفحة مهمة مسجلة. لا API لتعديل التدقيق.

## التنسيق

نظام تصميم واحد قابل للتغيير مركزيًا: Card، Button، Field، Select، DataTable، Notice، Dialog. العربية RTL متجاوبة ومضغوطة. الحقول 32px على الكمبيوتر و38px على الهاتف، خط 14px. الصفوف 34px و38px ثابتة، النص الطويل مختصر مع طريقة الوصول لقيمته على الهاتف ولوحة المفاتيح. حشو وهوامش قليلة.
جداول مصفوفة: ترتيب الرأس وتصاعدي/تنازلي، عدة أعمدة مع Shift وأولوية ثابتة عند تغيير الاتجاه، بحث وفلاتر وتصفح خادمي لقوائم البيانات، رؤوس ثابتة وارتفاع مرتبط بالشاشة. اختيار single/multi/os، معرفات مستقرة، اختيار كل الصفحة فقط مع وصف واضح. Select داخل الخلايا عند الحاجة.
مظهر فاتح/معتم ولون مختار لكل مستخدم في العام وكل شركة مستقلان. الألوان تؤثر على الأحزمة والأزرار والتنقل والجداول والأيقونات والحدود والتركيز والظلال الخفيفة والتنبيهات العامة. الأخطاء والتحذيرات والنجاح بألوان دلالية. تحقق التباين للسطوح الفعلية، لا خلفية واحدة. طلبات التحميل والحفظ مرتبطة بالنطاق والإصدار، وتمنع اختلاط العام والشركة أو إعلان حفظ تعديل أحدث لم يُرسل.

## المراحل التالية

الحسابات والعملات والفروع؛ ثم القيود والسندات وكشف الحساب بتوجيه المستخدم الأخير؛ ثم الأصناف والوحدات الثلاث والمخزون والمناقلات والتسويات؛ ثم الفواتير وربط ترحيلها؛ ثم الموظفون الموسعون والمذكرات والنقاط؛ ثم الدليل والمحتوى والدردشة والوصول الخارجي. التفاصيل المالية والمخزنية الأصلية تبقى مرجعًا ولا تنفذ كلها الآن. الطلبات الإضافية المحفوظة كاملة في reference/05_FUTURE_REQUESTS_RAW.txt ستراجع وتضاف على مراحل؛ تنظيمها وقراراتها المفتوحة في REQUESTS_REVIEW.md، ولا تعد كل اقتراحاتها التقنية تنفيذًا مطلوبًا في المرحلة الحالية.
