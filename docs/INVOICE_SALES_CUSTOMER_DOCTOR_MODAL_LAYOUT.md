# نافذة حفظ المبيعات: العميل والطبيب داخل الحقول — 2 نوفمبر 2026

## قرار واجهة المالك
- في مربع حفظ الفاتورة الذي يظهر عند اختيار جهة أو طبيب، تعرض جميع عناوين الحقول داخل إطار الحقل، بأسلوب الحقول العائمة المستخدم في كرت الصنف ورأس الفاتورة، لا كعنوان منفصل أعلاه.
- الحقول: بحث عن العميل بالرقم أو الاسم (اختياري)، رقم العميل (اختياري)، اسم العميل (اختياري)، اسم الطبيب أو الجهة. استخدم تنسيق `field floating-ready` و`data-label-raised="true"` مع نطاق CSS محدد `invoice-customer-doctor-form`.
- «رقم العميل» و«اسم العميل» متجاوران **في صف واحد على الكمبيوتر** عبر `invoice-customer-identity-row` بعمودين متساويين؛ على شاشات بعرض 680px أو أصغر يُعرضان تحت بعض لتفادي الضيق.
- أزيلت الجملة «السهمان ↑ ↓ للتنقل، وEnter للاختيار. يمكنك أيضًا كتابة اسم غير مسجل؛ عند حفظ الفاتورة يُنشأ كرت دون فئة ويُرسل تنبيه للمتابعة.» ولا تُعرض ملاحظتها البديلة في وضع عدم الاتصال. **لم تُلغَ وظائف الأسهم وEnter أو الحفظ الأوفلاين أو إنشاء الكرت والتنبيه**؛ التعديل خاص بالعرض فقط.
- أزيلت placeholders الطويلة المكررة من الحقول الأربعة لأن عنوان الحقل العائم يعطي الاسم. تظل labels قابلة لقراءة أدوات الوصول ومربوطة بـ ID، والبيانات من حالات React نفسها وبنفس رقم العميل كسلسلة لا يفقد الأصفار اليسارية.
