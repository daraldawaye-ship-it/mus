# إحصائيات الأصناف — الأساس الأول

هذه الدفعة تطبق جدول item_statistics مستقلًا لكل شركة وصنف، مع ملخص قراءة داخل كرت الصنف الموجود. لا يغير المستخدم الإحصائيات يدويًا، ولا تنشئ إحصائيات الصنف رصيدًا مخزنيًا بديلًا. stock_balances والمستندات والحركات المعتمدة تبقى المصادر.

## المتاح الآن

- كمية المخزون الحالية لجميع المواقع، وإجمالي المعارض والمخازن، بأصغر وحدة للصنف وبقيم نصية دقيقة تقبل السالب.
- مرجع آخر حركة فعلية، وآخر بيع عادي وآخر شراء عادي مرحّل، وآخر تسوية أحدثت حركة مخزون.
- عرض سعر آخر سطر شراء ووحدته وعملته واسم الحساب من بيانات الفاتورة التاريخية، مع تاريخ المستند والمنفذ. اسم المنفذ المعروض هو اسم حسابه الحالي.
- اختيار آخر عملية بترتيب معرف العملية، وآخر سطر في الفاتورة عند تكرار الصنف فيها؛ المردود لا يستبدل مرجع آخر فاتورة عادية.
- تحديث يدوي لقراءة الملخص وعند العودة لتركيز النافذة؛ لا زر تهيئة ولا تعديل لقيم الإحصائيات.

## التخزين والتحديث

الترحيل 021 ينشئ مفاتيح مركبة لشركة/صنف، ومراجع تاريخية مركبة إلى الحركة والفاتورة والسطر، وفهارس محددة لقراءة أحدث العمليات. تُملأ الأصناف السابقة آليًا عند الترحيل، ويُنشأ سجل الأصناف الجديدة عبر trigger.

تحديثات أرصدة المخزون وإضافة الحركة وإنهاء ترحيل الفاتورة تعيد اشتقاق ملخص الصنف في معاملة المصدر نفسها. تشمل المردودات والمناقلات والجرد، وتحافظ المناقلة على الإجمالي مع تغير توزيع المواقع. تتحدث المجاميع كذلك عند تغيير نوع الموقع. يشمل إجمالي المخزون المواقع المؤرشفة التي لها رصيد حتى لا يختفي المخزون بتغيير حالة الموقع. لا تدرج المراجع فواتير غير مرحّلة أو مردودات بوصفها آخر فاتورة عادية، وتشمل الفواتير المرحّلة ذات الصافي صفر. لا تسجل تسوية بفرق صفر كآخر حركة جرد، لأنها لم تنشئ حركة مخزون.

refresh_item_statistics(company_id,item_id) يعيد بناء السجل من المصادر، دون تعديل كرت الصنف أو المستندات. لا يوجد مسار API عام للحفظ أو إعادة البناء في هذه الدفعة. تحديث updated_at يعني وقت اشتقاق الملخص، وليس تاريخ آخر بيع أو تعديل كرت الصنف. إعادة إرسال فاتورة مقبولة لا تضاعف شيئًا، لأن الملخص مشتق من المصدر ولا يزيد عدادات عند كل طلب.

## الوصول والتحقق

GET /api/companies/:companyId/items/:id/statistics يعيد {statistics}. يلزم وصول الشركة والصنف وصلاحية الأصناف الحالية. بيانات المخزون تتطلب إتاحة وصلاحية أرصدة المخزون وحركاته؛ بيانات آخر بيع وشراء تتطلب إتاحة وصلاحية المبيعات والمشتريات وكرت الفاتورة. تُراجع قواعد المنع الصريح وإعدادات الصفحة على الخادم عبر directoryEntries؛ صلاحية كرت الصنف وحدها لا تكفي. تعاد الأجزاء غير المصرح بها null مع canViewStock/canViewCommerce، ولا تُجلب تفاصيلها التاريخية. مراجع صنف من شركة أخرى تعيد 404.

نجح فحص API واحد للأرصدة الأولية، والتحويل الدقيق 7×3، والشراء والبيع والمردود، والمناقلة والجرد، وثبات آخر فاتورة عادية، والعزل وحجب التفاصيل. يقتصر التحقق على هذا الفحص وTypeScript وبناء الواجهة، دون مجموعات المشروع العامة.

## الدفعات التالية

1. ملخصات يومية للكمية وعدد الفواتير والمردودات وصافي الحركة؛ ومنها فترات شهر/4 أشهر/12 شهرًا بتعريف زمني واضح.
2. تحليل أسعار الشراء بوحدة وعملة موحدتين، وقوائم البحث والتصفية الإحصائية وإعادة البناء الإدارية.
3. الحجوزات والبدائل والتركيبات وتواريخ اعتماد/عرض الجرد عند بناء بياناتها التشغيلية.

لا توجد عدادات زمنية أو حجوزات أو مقارنة أسعار أو مهمة تحديث يومية في الدفعة الحالية.
