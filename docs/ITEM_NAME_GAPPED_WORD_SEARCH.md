# البحث بكلمات غير متجاورة في اسم الصنف — 3 نوفمبر 2026

قرار المالك: الاسم «فادين كول اقراص مصوص» يجب أن يظهر عند كتابة «فادين مصوص» في فاتورة المبيعات والمشتريات أو البحث عن صنف، دون إلزام المستخدم بكتابة الكلمات الوسطى.

## التنفيذ
- تُطابق كلمات الاستعلام **بالترتيب** داخل الاسم أو حقول البحث ولو فصلتها كلمات أخرى؛ الكلمة الواحدة تعمل كما كانت.
- apps/api/src/services/lists.ts يقدم searchPattern(query, true) لربط كلمات الصنف بفواصل SQL % مع الهروب الآمن للرموز الخاصة. masterPage يفعّله للأصناف فقط بما يشمل commerce-options وitems، مع استمرار itemLookupSearchPlan المفهرس.
- apps/web/src/offline-shared-items.ts يستخدم matchesOrderedItemWords في الفهرس المحلي الجاهز والمسار المحلي الاحتياطي، ولا يعيد حساب الترتيب أو المخزون في كل بحث.
- apps/api/src/routes-item-options-list.ts يطبق البحث نفسه لصفحة قائمة الأصناف.
- لا تغيير لثلاثة أحرف كحد أدنى في اقتراحات الفواتير، أو الاختصار المباشر، وأولوية الباركود والرمز، وترتيب المبيعات والمتوفر، والعشرين نتيجة، أو صلاحيات المستخدم والشركة.

الاختبارات: tests/invoice-item-word-search.test.ts. يلزم فحص فعلي من حساب موظف ونسخة محلية كاملة بعد النشر.
